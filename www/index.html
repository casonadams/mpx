Built for Speed and Modern Workflows

Zero bloat, instant startup, and seamless orchestration for human engineers collaborating with AI agent harnesses.

⚡

Zero-Bloat Rust Core

No WebAssembly runtime, no embedded crypto suites or browser tunneling. Compiles in seconds, sub-10MB binary, and uses less than 5MB of memory.

🪟

tmux Parity & Tabs

Window tabs with Prefix + c (create), Prefix + n/p (nav), % (vertical split), " (horizontal split), and 1-character clean dividers.

🧭

Vim Navigation (hjkl)

Geometric directional pane focus: Prefix + h (left), j (down), k (up), and l (right) move seamlessly across your splits.

📋

100k-Line Vi Copy Mode

Movable cursor, Shift-V full-row highlighting, deep scrollback navigation, and instant yank (y) directly to system clipboard via pbcopy and OSC 52.

🤖

Native Model Context Protocol

Built-in stdio MCP server. AI agents (oh-my-pi, claude code, Cursor, Windsurf) can spawn tasks, query buffers, and supervise processes without terminal scraping.

🪢

Inter-Agent Virtual Pipes

In-memory circular FIFO channels allowing concurrent agents and sub-processes to exchange structured tokens and JSON streams with zero disk I/O.

Installation

Get started in seconds on macOS, Linux, or Windows.

Homebrew (macOS & Linux)

brew install casonadams/tap/mpx

Cargo (crates.io)

cargo install mpx

Prebuilt Static Binaries

Download cross-platform binaries directly from GitHub Releases:

  • macOS (Apple Silicon & Intel): .tar.gz
  • Linux (x86_64 & aarch64): .tar.gz, .deb, .rpm
  • Windows (x86_64): .zip (native ConPTY + Named Pipes)
