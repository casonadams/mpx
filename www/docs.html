mpx Documentation

An ultra-performant, zero-overhead terminal multiplexer engineered in Rust: 100% tmux-compatible, crash-resilient with automatic session recovery, zero-flicker rendering, and a sleek fuzzy command palette.

100% Offline & Zero Telemetry Guarantee
mpx contains zero analytics, tracking, or network calls. All IPC is strictly local via Unix sockets or Windows Named Pipes.

Keyboard Shortcuts & Navigation

By default, all multiplexer shortcuts are triggered via the prefix Ctrl-b (configurable via prefix in config.toml). If you pause after the prefix, a shortcut popup automatically lists common actions after which_key_delay_ms (300ms by default, 0 = instant).

Mouse Mode

  • Left Click: Focus clicked pane immediately.
  • Drag a Border: Resize the panes on either side of it.
  • Left Drag: Select text from the press point; release copies it to clipboard.
  • Scroll Wheel: Enter copy mode and scroll through terminal history.

Configuration

mpx reads its configuration from ~/.config/mpx/config.toml (or $XDG_CONFIG_HOME/mpx/config.toml). All configuration options are strictly validated.

Example config.toml

prefix = "C-b"          # Leader key: C-a, C-Space, M-b, etc.
remain_on_exit = false  # Keep panes open after child process terminates (or "failed")
history_limit = 64      # Number of dead panes kept in log history
scrollback_lines = 100000  # Scrollback lines per pane (tmux history-limit)
tmux_compat = true      # Export TMUX/TMUX_PANE and tmux shim (default: true)
allow_passthrough = true # Forward DCS tmux and OSC 52 clipboard sequences (or "all")
restore = true          # Recreate layout and resume processes across restarts
which_key_delay_ms = 300  # HUD popup delay (0 = instant)
display_panes_time_ms = 1000  # display-panes numbers stay up this long (0 = until a key)

[style]
border_active = "bright-green"
border_inactive = "bright-black"
border_marked = "bright-magenta"
border_style = "single"
status_bg = "dark-green"
status_fg = "black"

[bind]
"M-h" = "select-pane -L"
"$" = "command-prompt -I 'rename-session '"

# Process resumption rules for crash & reboot recovery
[[resume]]
name = "claude"
detect = ["claude"]
resume = ["claude", "--resume", "{id}"]
fallback = ["claude", "--continue"]
env_id = "CLAUDE_SESSION_ID"

[[resume]]
name = "omp"
detect = ["omp"]
resume = ["omp", "--resume", "{id}"]
fallback = ["omp", "--continue"]
env_id = "OMP_SESSION_ID"

[[resume]]
name = "nvim"
detect = ["nvim"]
fallback = ["nvim", "-S", "Session.vim"]

Session Restore

The daemon snapshots each session's layout as it changes. Every time a session starts, it brings back the windows, splits, and working directories, and tools resume their sessions through configured [[resume]] rules, whether the last run ended in a crash, a reboot, or mpx kill-server. Start with mpx --no-restore for a brand new state.

CLI Command Reference

mpx                              # Start or attach to default session
mpx ls                           # List sessions (tmux ls)
mpx list-panes                   # List panes with ids (%N) and status
mpx rename-session -t 0 dev      # Rename session (tmux rename-session)
mpx run --pty -- htop            # Run interactive command in PTY
mpx split -h -d -- htop          # Split side by side without focus (tmux flags)
mpx logs --plain --tail 50 <name> # Rendered scrollback
mpx send-keys -t %1 C-c          # tmux key names
mpx paste -t %1 --submit "text"  # Bracketed paste + Enter
mpx wait <name> --match 'done' --timeout 60
mpx restore                      # Restore workspace from last snapshot
mpx import-tmux [FILE]           # Print a config.toml fragment converted from tmux.conf (writes nothing)
mpx kill-server                  # Stop the session daemon
