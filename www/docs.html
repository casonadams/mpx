mpx Documentation

An ultra-performant, zero-overhead terminal and stream multiplexer engineered in Rust for humans and autonomous AI coding agents.

Getting Started

Running bare mpx automatically bootstraps a background daemon, opens your default shell in an interactive PTY, and launches the full-screen terminal interface:

# Start or attach to the default "main" session (just like tmux)
mpx

# Start or attach to a named session
mpx -s dev

Both Ctrl-B (default tmux prefix) and Ctrl-A (common rebind) are supported as leader keys out of the box.

Mouse Mode

  • Left Click: Focus clicked pane immediately.
  • Scroll Up: Automatically enters copy mode and scrolls history upward.
  • Scroll Down: Scrolls downward toward live output.

Model Context Protocol (MCP) Server

mpx features a native stdio Model Context Protocol (MCP) server conforming to the 2024-11-05 standard. AI coding assistants like oh-my-pi, claude code, Cursor, and Windsurf can orchestrate terminal processes directly without scraping ANSI screen sequences.

Agent Configuration (.mcp.json)

{
  "mcpServers": {
    "mpx": {
      "command": "mpx",
      "args": ["mcp"]
    }
  }
}

Exposed MCP Tools

  • mpx_run(command, args, name, pty): Spawn a background task or interactive PTY command
  • mpx_split(command, direction, args, name, pty): Split workspace pane and run command
  • mpx_list(): Query active stream nodes, types, PIDs, and exit statuses
  • mpx_read(name, tail): Retrieve clean unescaped scrollback logs
  • mpx_screen(name): Snapshot the 2D virtual terminal screen buffer
  • mpx_send(name, data): Send keystrokes / text directly to process stdin
  • mpx_wait(name): Await command exit and return exit code without polling
  • mpx_kill(name): Terminate a running node
  • mpx_pipe_write(name, data): Write message to inter-agent virtual pipe
  • mpx_pipe_read(name): Read content from an inter-agent virtual pipe

Inter-Agent Virtual Pipes

Virtual pipes are in-memory circular FIFO buffers allowing concurrent tools and agents to communicate with zero disk I/O:

# Create a named pipe channel
mpx pipe create agent_bus

# Stream structured tokens or JSON into the pipe
mpx pipe write agent_bus '{"action": "test_complete", "code": 0}'

# Read data from the pipe
mpx pipe read agent_bus

# List all active pipes
mpx pipe list

CLI Command Reference

mpx                      # Start or attach to default session
mpx -s dev               # Start or attach to session "dev"
mpx run -- cargo test    # Run command in managed task node
mpx run --pty -- htop    # Run interactive command in PTY
mpx list                 # List active nodes (ls alias)
mpx logs <name> [-f]     # Read or stream logs
mpx send <name> <text>   # Send input to stdin
mpx wait <name>          # Wait for process exit code
mpx kill <name>          # Terminate a node
mpx stop                 # Stop background daemon (kill-server alias)
mpx mcp                  # Launch stdio MCP server
